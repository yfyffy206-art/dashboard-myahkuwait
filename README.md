# dashdash-kuwait

المصدر الأصلي القابل للتعديل للوحة تحكم الزوار.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

قبل التشغيل، انسخ `.env.example` إلى `.env.local` واملأ متغيرات `FIREBASE_*` المطلوبة. ملف `.env.local` مستثنى من Git.

## الفحص والبناء

```bash
pnpm check
pnpm build
```

## الملاحظات

- ملفات الواجهة الأصلية موجودة داخل `client/`.
- الأصول والسكريبتات الحالية موجودة داخل `client/public/assets/`.
- لا يتم تضمين `node_modules` أو الملفات المضغوطة/المؤقتة؛ يتم تثبيت الاعتماديات بواسطة `pnpm install`.
- يتضمن المصدر إدارة المنتجات، التمرير المتجاوب، زر العودة، والتنبيهات الصوتية ثلاثية المراحل.
- تُقرأ إعدادات Firebase من متغيرات البيئة أثناء التطوير والبناء. أضف المتغيرات نفسها إلى إعدادات بيئة النشر.
- إعدادات Firebase التي تصل إلى المتصفح عامة بطبيعتها؛ لا تضع كلمات المرور أو مفاتيح الخادم فيها. حساب اللوحة يُدار من Firebase Authentication.
